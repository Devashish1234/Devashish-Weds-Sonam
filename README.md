# Devashish weds Sonam

A mobile-first wedding invitation for Devashish Shukla and Sonam Durga.

## Run locally

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`.

## GitHub Pages

The `main` branch deploys automatically to GitHub Pages through the workflow in `.github/workflows/deploy.yml`. The Vite base path is configured for the `Devashish-Weds-Sonam` repository.
